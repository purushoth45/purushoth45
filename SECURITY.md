# Security Policy

## Reporting a vulnerability

Please do not open public issues for security bugs.

If you discover a vulnerability or a sensitive issue, contact the maintainer privately through the email listed in the profile README or through a direct GitHub contact method.

Please include:

- A clear description of the issue.
- Steps to reproduce it when possible.
- The impact and severity you observed.
- Any suggested mitigation or fix.

## Response expectations

We aim to review sensitive reports promptly and act responsibly when a legitimate issue is reported.
